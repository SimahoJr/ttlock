# Shannon Smart Access

## Structure

- `index.html` — page markup and UI structure
- `css/style.css` — all existing CSS
- `js/main.js` — all existing JavaScript and bridge logic
- `images/` — place application images here

## Image usage

From `index.html`:
```html
<img src="images/logo.png" alt="Logo">
```

From `css/style.css`:
```css
background-image: url("../images/background.png");
```

The existing JavaScript bridge and UI behavior are kept unchanged.
